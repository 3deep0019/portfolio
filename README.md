# Trideep Ghosh — Portfolio

A modern, fully responsive personal portfolio built with **Vue 3**, **Tailwind CSS**, and **Motion for Vue** (Framer Motion for Vue).

## Features

- Clean, minimalist design with dark/light mode toggle
- Fully responsive layout (mobile-first)
- Smooth scroll-triggered animations
- Semantic HTML with accessibility in mind
- Sections: Hero, About, Skills, Projects, Experience, Contact

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Customization

Edit `src/data/portfolio.js` to update skills, projects, experience, and social links. Replace `/public/resume.pdf` with your actual resume file.
